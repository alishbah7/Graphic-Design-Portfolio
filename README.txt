# Graphic Design Portfolio

## Setup
1. Extract the ZIP.
2. Put your eight project images inside the `images` folder.
3. Keep the filenames exactly as listed below (or update the paths in `index.html`).
4. Open `index.html` in your browser.

## Required image filenames
- DateFlyer.png
- FoodMenu.png
- HomeMadeSnacksMenu.png
- M&ASnacksMenu.png
- SoundBlast1.png
- SoundBlast2.png
- SoundBlast3.png
- SoundBlast.png

The SoundBlast logo preview tiles already have a white background so transparent logos remain visible. The popup also uses a white image canvas.

AOS and Google Fonts load from their CDNs, so an internet connection is needed for those external assets.
